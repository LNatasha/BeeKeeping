# Colmeias 1.1 — What's New (App Store Connect)

## Português (PT-PT)

Novidades nesta versão:
- Novo Perfil de Apicultor: regista o teu número de apicultor, associação, número de colmeias registadas e a localização GPS do teu apiário.
- Botão "Usar Localização Atual" para preencher automaticamente as coordenadas.
- Pequenos ajustes de interface.

## English

What's new in this version:
- New Beekeeper Profile: record your apiarist registration number, association, registered hive count, and your apiary's GPS coordinates.
- "Use Current Location" button to auto-fill coordinates.
- Minor UI polish.
